# VALKYR01: empty C140 projection is not an extraction failure

User supplied a successful VALKYR01 export with zero bank candidates and
unmeasured retained/PDX statistics. Inspected that exact source and its existing
export diagnostics read-only; no private reconversion or listening performed.

The input has 88200 source samples (2 seconds), 96 OPM writes, one C140 write
(to register 0x1FA, value zero), and one C140 ROM declaration with a 1048576-byte
logical size but zero payload bytes. There are no C140 voice/key-on writes.
Native source issues are empty. Bank source gates/assets/playbacks are all zero.
The compiled output has seven stored FM NOTE commands and zero PCM NOTEs.

No PDX is needed for this input. pcm_bank_stats.summarize deliberately leaves
retained/binary quantities unknown when there is no current owned PDX. Thus the
console unmeasured values here describe an inapplicable packed-bank measurement,
not missing source ROM that was actually read or a failed capture. Do not turn
an empty ROM declaration into invented samples or force PDX creation. This does
not validate the C140 route for other songs that actually use voices.

Potential later reporting refinement: explicitly display no PCM playback / PDX
not required when native analysis conclusively produces an empty bank. Keep
this distinct from genuine incomplete or failed statistics. No production code
changed for this investigation. MSX run_test.sh is user-running; do not rerun or
modify that checkout until user completion notification.
