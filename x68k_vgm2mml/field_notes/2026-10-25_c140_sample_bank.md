## Implementation
C140 native immutable writes, ROM blocks/coverage, reset assumptions, State and
write-observed Segments are independent of audible voice reconstruction. Shared
VGM traversal preserves command identities and replay occurrences. Header fields
are bounded by VGM version and command-data boundary. Unused clock declarations
do not select a source route. Support is single-chip System 2 / System 21; type2
ASIC219, dual/unknown variants are explicit projection blockers.

Native clock is floor(effective_clock/288), preserving float32 frequency math.
Addresses latch on Key-On; repeated writes retrigger; live frequency/bank/volume,
zero-frequency pause, silent advancement, interpolation and natural termination
follow the pinned runtime. C140 compression is custom, not G.711.

Per-voice capture yields reusable assets and playback rows. Held controls become
finite baked variants; no whole-song mix fallback. Shared PCM8 allocation,
similarity/budget96 reduction, EX-PDX packing and byte budgets remain target
stages. Auto policy selects best-effort for the exact C140-derived origin;
explicit strict rejects recorded transcoding losses. Native evidence is retained
before projection rejection and force never invents missing ROM content.

Complete one-shot expansion is optional. Missing bytes only in an unplayed tail
fall back to captured audio; missing bytes actually read remain hard errors.
Completions cache source identity excluding onset gains and use an independent
32-million-native-frame budget before capture. Only one completion ROM snapshot
is retained. Fallback reasons/cache/frame counts are inspectable. Architect
review found these issues and implementation/tests addressed them.
